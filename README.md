# Telefonia Retrô

## Aluno
Eduardo Vedana Danielli

## Descrição
Aplicação desenvolvida em Angular para apresentar informações e preservar a história de aparelhos celulares clássicos que marcaram época.

## Funcionalidades
- Exibição do catálogo de celulares clássicos;
- Visualização de detalhes e especificações técnicas completas em modal;
- Identificação de disponibilidade, preços e descontos dos aparelhos;
- Sistema fictício de login (Área do Colecionador);
- Envio e gerenciamento de depoimentos de colecionadores através de formulário interativo;
- Navegação intuitiva entre as seções da página.

## Tecnologias
- Angular
- TypeScript
- HTML
- CSS

## Como Executar
1. Baixe ou clone o repositório.
2. Execute `npm install`.
3. Execute `ng serve`.
4. Acesse `[http://localhost:4200](http://localhost:4200/)`.
